# CSC Smart Form Filler — Chrome Extension\n\nLoad this folder as an unpacked extension at `chrome://extensions` with Developer mode enabled. Open a supported form page, click the extension, detect fields, review candidate values, then explicitly fill matched standard fields.\n\nThis MVP uses `activeTab` only, does not request broad site access, excludes password/hidden/file/submit controls, never submits a form, and does not bypass CAPTCHA, OTP, login, or portal restrictions. Compatibility is limited to ordinary visible HTML inputs and textareas with recognizable labels.\n
